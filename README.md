# python‑autovehicle
Learning and implementation of autonomous vehicle algorithms with Python.

This repository is built for personal study of self‑driving technology. It implements classic autonomous driving core modules, including vehicle kinematics, path planning, trajectory optimization, motion control and simplified perception simulation.

### Main Contents
- Vehicle kinematics & dynamics model
- Path‑planning algorithms: A*, RRT, artificial potential field
- Trajectory generation and smoothing
- Motion controller: PID, pure pursuit, Stanley controller
- Simple simulation for algorithm verification

### Requirements
- Python 3.8+
- NumPy, Matplotlib, SciPy

> Note: This is a learning‑oriented project, not for real‑vehicle deployment.
